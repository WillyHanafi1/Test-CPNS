# Aturan kerja proyek

- Kerjakan perubahan langsung di branch utama, `main`.
- Jangan membuat branch baru, termasuk branch dengan awalan `codex/`.
- Jangan pernah melakukan `git push` atau mengunggah perubahan/commit ke remote melalui cara lain.
- Biarkan perubahan tetap lokal di `main`. Pertahankan seluruh pekerjaan yang belum di-commit saat berpindah branch.

Aturan ini merupakan instruksi eksplisit pemilik proyek dan berlaku untuk seluruh repositori.
