# Aturan kerja proyek

- Kerjakan perubahan langsung di branch utama, `main`.
- Jangan membuat branch baru, termasuk branch dengan awalan `codex/`.
- Pemilik mengizinkan commit dan `git push` ke `main` secara tetap; tidak perlu meminta izin push lagi.
- Jalankan pemeriksaan yang sesuai sebelum push. Pertahankan seluruh pekerjaan yang belum di-commit saat berpindah branch.

Aturan ini merupakan instruksi eksplisit pemilik proyek dan berlaku untuk seluruh repositori.
